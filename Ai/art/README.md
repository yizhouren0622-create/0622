# 《Ai》美术方向 · 图标与标题 UI 备选

气质：**陪一个人生活的空气**——水彩、浅色、通透、风与窗。  
不是赛博、不是恐怖 meta、不是攻略看板。

## 色板（建议）

| 用途 | 色感 |
|------|------|
| 天空 / 空气 | 薄天蓝、雾蓝灰 |
| 傍晚 | 暖琥珀、薄橙，不用霓虹紫 |
| 纸 / UI 底 | 水彩纸白、奶油纸纹 |
| 文字 | 炭黑 / 墨灰，略带水彩渗边 |
| 点缀 | 第二根冰棒的浅色渍、窗帘透光 |

**避免：** 紫对白、赛博霓虹、厚描边卡片、圆角胶囊按钮、多层外发光。

### UI 原则（落地到引擎时）

1. **品牌先于菜单**：第一屏主角是 **Ai**，菜单是安静的字，不是按钮墙。  
2. **全出血氛围底**：教室窗 / 河堤 / 长椅，不要插图小卡。  
3. **选项 = 轻墨字 + 水彩底晕**，不要卡片框、不要胶囊。  
4. **对白框**用半透明水彩条，边缘软，不要硬矩形 HUD。  
5. Meta（ESC、窗口）用**极淡灰字**，别抢日常空气。
