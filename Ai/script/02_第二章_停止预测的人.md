# Chapter 2｜停止预测的人

**视角：** ài（玩家第一次离开男主容器）  
**承接：** Ch1 烟花夜・Emotion Uploaded  
**情绪：** 开头日常，异样慢慢堆；烈度高于 Ch1，但**不当场灌世界观**。  
**女主：** 普通女高，正常智商；不安、会懵、会自己查；说话像真人。  
**信息规则：** 她只能根据**当下看见/听见的事**和**第一章已经发生过的事**行动——不突然懂「游戏」「维护层」「Archive」。  
**交互：** 玩家几乎每场都有回应；**前置选项**决定后续台词与可解锁内容（见旗标表）。  
**结构：** 异样 → 探索 → 卡进灰房间 → 短发 → 踩进没钉好的井盖 → Ch3  
**BE：** 见 2-BE。  
**伏笔（给 Ch4）：** 本章玩家若多次「帮她变正常／别查了／你看错了」，会抬高后文 **Shape** 倾向；若「等／记得／别改」，抬高 **Autonomy**——**不在此章解释术语。**
