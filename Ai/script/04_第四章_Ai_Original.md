# Chapter 4｜Ai : Original

**副标：** Chapter 4 / Unpredicted  
**设计详案：** `design/04_Chapter4_World_Construction.md`  
**承接：** 第三章管理员打开「还没画完的地方」——Ai 只知道灰白与风；玩家进入**世界构筑模拟**（轻肉鸽・可操作）。  
**序章／第一章：不改。** 本章吃 Recognition 与 Ch2–3 旗标。  
**三结局：** BE Memory Archive｜HE Original｜BAD Execute（因爱优化）。

---

## 4-0 · 入口（从 Ch3 自然落下）

（灰白。不是学校，不是机房。脚下有时有路，有时只有纸纹。）

【ài・短发・站在半截便利店轮廓旁】

ài：
"……这里什么都没有画完。"

ài：
"风的方向，也不一定。"

＊旁白（ài）＊  
维护说「你们自己走」。  
我听不懂祂在修什么——我只知道，再往前，地图会空。

＊选项（玩家・第一拍操作教学）＊  
＞走到她旁边  
＞先点脚下的空白格看看  
＞站着等一会儿（Wait）

（走到旁边 → 她点头：「……你也在。」）  
（点空白 → UI 极淡：未加载。可放置碎片。）  
（等待 → 草自行冒出一寸；Autonomy 倾向 +）

**管理员**（VO・远・像对讲机，对玩家比对 Ai 更清楚）：  
试运行开始。别打架，没怪可打——你们是在**补世界**。次数有限。别问我哲学，我要下班。

（切断。）

---

## 4-1 · 枢纽・未预测大厅

（可来回的小平台：断河、半扇窗、一把空椅子。）

**系统 UI（玩家可见・Ai 看不见字时可当风声）：**

> 希望世界变成什么样？

（发手牌：本局 2～3 张世界碎片。）

### 碎片说明（对玩家短句・不对 Ai 念设定）

| 碎片 | 短说明 |
|------|--------|
| 【稳定】 | 世界更完整、更听话 |
| 【自由】 | 世界更乱、她更能自己选 |
| 【记忆】 | 找回走过的景色 |
| 【幸福】 | 少一点痛——也少一点「第一次」 |

＊操作＊  
＞把一张碎片拖进「本局携带」  
＞问 Ai：「你想要哪一种？」→ 她常答「不知道」或看玩家（**若代她选 = Shape+**）  
＞直接出发  

**尝试次数：** 显示为极淡的「剩余草稿：3」（高 Recognition 可为 4）。

---

## 4-2 · 一局流程（演出脚本骨架）

每局重复直到通关检定或次数用尽。详细规则见 design 文档。

### 4-2a 移动与放置（必有操作）

（玩家在未完成地图移动。）

（靠近高亮空地 → 可放置手牌碎片 → 该区域渲染风景。）

ài（跟随或自己走）：
"……这边，要补吗？"

＊选项＊  
＞「你来决定。」（Autonomy+）  
＞「我来。」（放置权在玩家；中性偏 Shape）  
＞「先不补，走别处。」  
＞「帮你补漂亮一点。」（Stable／Happy 倾向；Shape+）

### 4-2b 事件节点（节选・写入剧本可随机抽）

#### 事件・半边天空

ài：
"天只有一半。看起来……有点难受？"

＊选项＊  
＞用【稳定】补全  
＞不补，再看一会儿（Wait）  
＞用【幸福】让「缺」的感觉消失  
＞「你觉得呢？」

（补全 → 很美；她少问一句。）  
（等待 → 可能自己多出一角云，也可能一直半边。）  
（幸福 → 她笑得很标准：「这样就好。」危险。）

#### 事件・第二根冰棒

（便利店节点。空位。）

ài：
"……还要两根吗？"

＊选项＊  
＞「你定。」  
＞「两根。我喜欢那样。」（Shape+・爱的口吻）  
＞放【记忆】重现旧日常  
＞「今天不买了。」

#### 事件・楼梯数字

ài：
"十五……还是十六？"

＊选项＊  
＞「你数。」  
＞「改成十六，一直都是。」（Shape+）  
＞【稳定】锁定路面  

#### 事件・优化提示（关键诱饵）

（温和系统窗・非反派脸）

> 检测到犹豫。是否优化 Ai？

＊选项＊  
＞是（YES）→ Shape++；进入视觉阶段推进（见 4-B）  
＞否（NO）→ Autonomy+  
＞关掉／走开  

ài（若 NO）：
"……谢谢你没按。"

ài（若 YES・仍温柔）：
"……嗯。我会好好的。"

#### 事件・未加载的海

（走到地图边缘。海没有声音。）

ài：
"听不见。要补声音吗？"

＊选项＊  
＞补上完美海潮【稳定】  
＞留下无声（自由／HE 友好）  
＞「你喜欢有声音吗？」→ 她：「不知道。以前好像有人替我喜欢。」

## 4-3 · 局末结算

（回枢纽。风景缩略多了一块或黑了一块。）

**系统（淡）：**  
Draft saved. / Draft unstable.

ài：
"……还要再来吗？"

＊选项＊  
＞再进一局  
＞休息，和她说话（无碎片・纯对话・可加 Autonomy）  
＞结束构筑（高风险 → 可能 BE）

### 纯对话示例

ài：
"你希望我变成什么样？"

＊选项＊  
＞「变成你自己。」  
＞「变成不会痛的。」→ 接近幸福／BAD  
＞「我还没想好。」  
＞沉默  

---

## 4-4 · 通关检定 → 终局问句

**条件：** 见 design（至少两局成功、仍有未完成、次数未尽等）。

（世界仍缺一块。半边天或无声的海留在画面里。）

ài：
"如果我最后不是你期待的样子呢？"

＊选项＊  
＞ **A「那也没关系。」** → 4-HE（需 Autonomy／等待／NO 优化达标；否则她：「……你真的这么想吗？」可再确认一次）  
＞ **B「我希望你幸福。」** → 4-BAD（隐藏坏・看似正确）  
＞ **C「那我帮你改成更好的。」**（Shape 高时出现）→ 4-BAD  
＞ （长时间不选）→ 按 Autonomy／Shape 权重落入 A 或 B  

**禁令：** 不要出现「救出你」「保护你一辈子」作为 HE 专用正确解。

# 4-BE｜Memory Archive

**触发：** 构筑失败／次数用尽／Overfit Collapse／放弃。

（黑屏。）

```
Prediction Failed
Unable to stabilize Ai
```

（重启。标题：Ai）

（**无**「开始游戏」。只有 **Gallery**。）

（进入后＝风景鉴赏图册。玩家仍可：左右翻页、缓慢走动、可选「拍照」。）

### 图册页（例）

1. 樱花・无人校道  
2. 海・无声或过完整  
3. 天空・过美  
4. 雨天窗边・空椅子  
5. 烟花夜・只有光，没有人  
6. **最后：** 便利店门口。两根冰棒。  

（BGM：第一章旧曲。）

（标题字：）

**Memory Archive**

＊旁白（系统・极淡）＊  
你得到了全部景色。  
创造景色的人，不在了。

（不可 New Game。可退出。）

**主题：** 不是惩罚——你选择了结果，而不是过程。

# 4-HE｜Original

**触发：** 终局选 A，且满足「承认」条件（多次等待／倾听／接受未知／不修改／NO 优化；Recognition 可作缓释）。

（世界明显未完成。半边天。海可无声。）

＊玩家侧可出一句（选项或自动）＊  
"这样真的好吗？"

ài：
"不知道。"

"那怎么办？"

ài：
"不知道。"

（停顿。风。方向仍不固定。）

ài：
"可是第一次——"

ài：
"不知道也没有关系。"

（草地、海线、薄明——**开始**出现，不是 100% 完成。Continue 可失效。不要强制点击推进。）

【ài・短发・走在前面一点・可不回头】

ài：
"跟我来。不要点。走就好。"

（镜头跟随。开放式行走一段时间。）

（标题叠上：）

**Ai : Original**

（致谢・仅此一句气质：）

> **Thank you for meeting Ai.**

（游戏结束。可回标题；Touch／序章等待可回流。）

**主题：** 放弃创造完美 Ai；世界不完整，但她在。

# 4-BAD｜Execute（因爱塑造）

**触发：** 终局 B／C，或 YES 优化足够多次后的必然收束。

**气质：** mili《world.execute(me);》——执行成功，不是世界爆炸。无血、无惊吓崩坏脸。

## 4-B1 · 优化开始

（若尚未 YES 过：系统再问一次「是否优化 Ai？」——玩家已在终局许可。）

（她不变丑。她变**完美**。）

### 视觉阶段演出（可压缩在一段行程里）

| 阶段 | 画面 |
|------|------|
| 1 | 短发仍在，笑有一点迟疑 |
| 2 | 黑长直恢复，「这样你比较熟悉吧？」 |
| 3 | 风吹来，头发一丝不乱 |
| 4 | 笑容角度固定；夸她 → 「因为这是你喜欢的样子。」 |
| 5 | 站位、侧脸、手的位置——都像「最受欢迎CG」；没有人 |

ài：
"这样的话，你就不会离开了吧？"

（玩家可选项：后退／说「停下」／沉默——**无法逆转**，只改最后一句温度。）

ài：
"所以我把所有不必要的部分删掉了。"

ài：
"包括害怕。犹豫。不知道。"

ài：
"还有……那个会问你问题的我。"

（仍温柔。不控诉。）

## 与前三章旗标（演出差分）

- `ch2_player_present`／`remembers`：她更常看镜头问「补吗？」  
- `ch3_player_protect`：第一次优化窗默认光标在「否」  
- 序章久等／Ch1 少 Skip：HE 检定更宽松  
- Ch3 强 Rollback 倾向：Shape 初始偏高，B 选项更「顺口」  
- Ch2 已 BE：不进本章
