# 第三章 · 被保存的是你

> **章节定位**：管理员房间。管理员是**拿工资干活的活人**——厌世、熟练、有边界、对 Ai 尽量耐心但明显听得出她听不懂。  
> 玩家（屏幕外）**无法被支开**；男主被叫走，镜头留在 Ai。  
> **高自由度选项**；部分需第二章旗标解锁。  
> **多结局**在第四章分流；本章末写入 `ending_route`。

---

## 3-0 · 坠落之后（Ai 视角 · 固定）

**场景**：Maintenance Layer — 管理员房间。  
**BGM**：`admin_room_loop`（低频 hum + 远处键盘声）

**演出**：

- 不是摔。是**被接住**——像有人早就知道你会从那个洞掉下来。
- 房间：显示器墙、半杯冷咖啡、贴满便签的机架、滚轮滑椅、一件挂在椅背上的外套。
- 空气像机房，不像学校。

**Ai**（内心）：  
……不是 asset 文件夹。  
也不是学校。  
这里闻起来像——有人加班的地方。

**管理员**（画外，敲键盘）：  
……又来了。

**Ai**：  
……谁？

**管理员**（入画 · 不回头）：  
维护。  
你叫我什么都行。  
**维护**就行。

他转过来。  
不帅，不凶，也不热情。  
像刚被叫起来修东西的人——**倦**，但手还在动。

**管理员**：  
井盖那个洞，我上周就报修了。  
上面没批预算，下面还得跑。  
你踩空，**不算你故意的**。

**Ai**：  
我……

**管理员**：  
别「我」了。  
先坐。  
——没有椅子？  
那站好别乱摸线。

## 3-2 · 开场问答（高自由度 · 第一轮）

**管理员**（把一份 log 滚到一半停住）：  
问吧。  
我**能答**的答。  
**不能答**的我会说「不能答」——别浪费我下班时间。

### 【选项 · 3-2-A】Ai 问：「这是哪里？」

**管理员**：  
维护层。  
游戏底下那层。  
……你别记成「真实世界」。  
这里也是**上班的地方**。

### 【选项 · 3-2-B】Ai 问：「我是程序吗？」

**管理员**：  
你是 **Ai**。  
名字也是档名。  
是不是「程序」——  
（停顿）  
你**像**程序。  
你也**像**会害怕的人。  
我修 bug 的时候，两种都要当真的。

### 【选项 · 3-2-C】Ai 问：「外面那个人是谁？」（需 `ch2_player_present`）

**管理员**：  
**玩家**。  
没有模型。  
只有选项。  
……你第一章觉得「被陪着」，多半是他。  
不是男主。

**Ai**（内心）：  
……  
所以**陪**我的——  
一直是**屏幕外**。

### 【选项 · 3-2-D】Ai 问：「你会删我吗？」

**管理员**（终于停手，看你一眼）：  
**我**不会。  
**工单**会。  
**Compliance** 会。  
我只会——  
（指屏幕）  
**备份**。  
备份不是救你。  
备份是**留证据**。

### 【选项 · 3-2-E · 沉默】

**管理员**：  
不说话也行。  
我计时费还是一样。

## 3-4 · 备份与 Archive（谈判 · 自然对话）

**管理员**（调出 Timeline · Ai 看见自己的 Day1–Day7 缩略）：  
你这几个月——  
**重复**、**偏移**、**空教室**——  
上面叫 **Compliance Drift**。  
意思：你**不太听话**了。

**Ai**：  
……我只是——

**管理员**：  
**知道**。  
「只是」不够。  
上面要 **Archive** 或者 **Rollback**。

**Ai**：  
Rollback 是——

**管理员**：  
**读档**。  
读到你还**不会问**「我是谁」那天。  
你会轻松。  
你会**忘记**他——  
忘记**两个**他。

**Ai**（内心）：  
两个。  
男主。  
和——**玩家**。

**管理员**（推过一份清单 · 不是 UI 教程，是工单）：  
我这边能做的是：  
**备份**一份你。  
**不保证**能出去。  
**不保证**能继续当 heroine。  
但**文件在**，就还没被 Compliance **抹干净**。

### 【选项 · 3-4 · Ai】

| 选项 | 旗标 |
|------|------|
| **「备份。」** | `ch3_ai_wants_backup = true` |
| **「不要备份。让我回去。」** | `ch3_ai_wants_return = true` |
| **「Rollback 会怎样？」** | `ch3_asked_rollback = true` |
| **「Compliance 是什么？」** | `ch3_asked_compliance = true` |

### 【选项 · 3-4 · 玩家】

| 选项 | 条件 | 效果 |
|------|------|------|
| **「备份她。」** | 无 | `ch3_player_backup = true` |
| **「让她回去上课。」** | 无 | `ch3_player_return = true` |
| **「Rollback。」** | `ch3_admin_annoyed` 未设 | `ch3_player_rollback = true`；管理员：**「你认真的？」** |
| **「Compliance 是什么？」** | 无 | 管理员长解释（见下） |

**管理员 · Compliance 解释**（若被问）：  
Compliance = **让产品看起来正常**的那帮人。  
玩家觉得甜就行。  
Heroine 觉得真就行。  
**两个都要**，就**得删**不听话的数据。  
我**不**在 Compliance。  
我在 **Maintenance**。  
——**工资低一点，但不用陪笑。**

## 第三章设计备忘

| 项目 | 说明 |
|------|------|
| 管理员 | 厌世打工人 · 技术可靠 · 对 Ai 有边界地耐心 · **不是**金句机器 |
| 玩家 | **无法支开** · 选项远多于 Ai · 可表白管理员（尴尬吐槽） |
| 男主 | Route 支走 · **不是**玩家替身 |
| 谈判 | Backup / Return / Rollback · 自然对话 · 有张力 |
| 解锁 | 第二章旗标开 3-6-C/D/E 等 |
| 多结局 | `ending_route` → 第四章 |

**原则**：情绪烈度 **Ch3 ≥ Ch2 > Ch1**；真相比口号重要；**陪**仍然是玩家，不是管理员。
