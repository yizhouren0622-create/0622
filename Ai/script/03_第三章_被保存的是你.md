# 第三章 · 被保存的是你

> **定位：** 管理员房间。管理员 = 拿工资的维护，**无性别**（人称用 **祂**），厌世、熟练、有边界；对 Ai 尽量耐心，但**经常答到一半就停**——她听不懂时祂不硬灌。  
> **信息规则：** 当下不倾倒世界观。术语只在**被问到**且**有前置旗标／玩家追问**时，用大白话短答。  
> **玩家：** 支不走；选项多；许多选项依赖 Ch2 旗标。  
> **交互：** 谈判多轮；中途可插话；Ai 与玩家意见可冲突。  
> **结局路由：** 写入 `ending_route` → Ch4。

## 3-0 · 坠落之后

**场景：** 像机房的办公室——显示器墙、冷咖啡、便签、滑椅、椅背外套。  
**BGM：** 低频 hum + 键盘。

（不是摔——像被接住。）

＊旁白（ài）＊  
……不是那个灰仓库，也不是学校。这里闻起来像有人加班。

**管理员**（画外，敲键盘）：  
……又来了。

ài：
"……谁啊？"

**管理员**（入画，不回头）：  
维护。你叫我什么都行，维护就行。

（祂转过来：不显眼也不凶，也不热情——刚被叫起来修东西的倦，手还在动。）

**管理员**：  
井盖那个洞我上周就报了，上面没批钱，下面还得跑——你踩空，不算你故意的。

ài：
"我……"

**管理员**：  
别「我」了，先站好，别乱摸线。没有椅子就算了。

＊选项（玩家・第一拍）＊  
＞「她没事吧？」→ 管理员：「生命体征正常。别用游戏词——她听得见。」（`ch3_player_protect` 倾向）  
＞「这是哪？」→ 管理员看观众侧一眼：「你等她自己问。」  
＞沉默

## 3-2 · 开场：她问、祂答（短答・可多轮）

**管理员**：  
问吧。能答的答，不能答的我说不能——别耗我下班。

### 选项池（Ai・每轮选 1；建议 2～3 轮后管理员催「说正事」）

| 选项 | 条件 | 管理员答法（大白话・短） | 旗标 |
|------|------|--------------------------|------|
| 「这里是哪里？」 | 无 | 「上班的地方。修你们学校出的毛病的。别想成天堂。」 | `ch3_asked_where` |
| 「我是什么？」 | 无 | 「你是 ài。别的——你现在听了也只会更慌，过会儿再说。」 | `ch3_asked_what_am_i` |
| 「外面那个人是谁？」 | 需 present / remembers / admitted | 「点选项的那个。没身子。你要是觉得被陪着，多半是他，不是男主。」 | `ch3_asked_who_outside` |
| 「你会删我吗？」 | 无 | 「我不会。上面可能会。我最多能帮你留一份拷贝。」 | `ch3_asked_delete` |
| 「灰房间那是什么？」 | `ch2_entered_asset` | 「不该进的地方。你绊进去的，不是功能。」 | |
| 「我手机里记的云……」 | `ch2_log_anomaly` | 「……你还记了。行，算你仔细。」（不解释预测网络） | |
| 「云边上闪过一下」 | `ch2_saw_glitch` | 「显示出问题。你没疯。」 | |
| 「我拍了张照片」 | `ch2_has_photo` | 「拿来——嗯，别外传。对我有用。」 | |
| 「短发还会变回去吗？」 | `ch2_cut_hair` | 「会有人想给你变回去。记不记得住，另说。」 | |
| 「你说的上面是谁？」 | 管理员已提「上面」或玩家追问 | 见 3-2b | `ch3_asked_upper` |
| （沉默） | 无 | 「不说话也行，计时费一样。」 | |

**【若条件不满足】** 选项不出现或灰显；误点时管理员：「你还没资格问这个——或者说，你自己都还没确认过。」

### 3-2b · 「上面」只漏一点

**管理员**（不耐烦又不得不说）：  
上面就是……要你们看起来「正常」的人。甜就行，怪就删。我不是他们。我修东西，拿工资。  
——别问组织名，问了你也背不下来。

（**不要**长段 Compliance 课；单词 Compliance 仅在玩家后文主动点举报键／管理员警告时出现。）

## 3-4 · 正事：拷贝，还是回去（谈判・多轮）

**管理员**（调出一排缩略：像她这几个月的日子）：  
你最近老跑偏。上面不喜欢。他们要嘛把你**拷一份存着**，要嘛把你**倒回去**——倒到你还不怎么会问怪问题的时候。

ài：
"倒回去……是忘记吗？"

**管理员**：  
差不多。轻松，省事，他们高兴。

ài：
"拷一份呢？"

**管理员**：  
拷一份＝我这留底。不保证你能回学校当没事人，但至少不是一笔勾销。  
——我**不**保证英雄结局。我保证文件还在。

### 交互轮 A（玩家可插话）

＊选项＊  
＞对 Ai：「听听祂怎么说拷贝。」  
＞对 Ai：「别信祂。」  
＞对管理员：「用她听得懂的词。」  
＞沉默让他们谈  

（「用听得懂的词」→ 管理员叹气，改口：「就是备份。U盘那种感觉。懂？」）

### 交互轮 B（Ai）

| Ai 选项 | 旗标 |
|---------|------|
| 「……那就拷一份吧。」 | `ch3_ai_wants_backup` |
| 「我想回去上课。」 | `ch3_ai_wants_return` |
| 「倒回去会怎样？说清楚。」 | `ch3_asked_rollback_plain` → 管理员短答：「你会轻松，会忘一些人。包括可能忘掉**两个**——男主，和外面那位。」（仅当她已问过外面／有 present 旗标时提「两个」；否则只说「会忘一些人」） |
| 「我想听听……后面那位的意见。」 | 需有名场面条件；否则管理员：「她还不确定有没有那位。」 |

### 交互轮 C（玩家）

| 玩家选项 | 条件 | 效果 |
|----------|------|------|
| 「备份／拷贝她。」 | 无 | `ch3_player_backup` |
| 「让她回去上课。」 | 无 | `ch3_player_return` |
| 「倒回去。」 | 无 | `ch3_player_rollback`；管理员：「你认真的？」 |
| 「上面到底要干嘛？」 | `ch3_asked_upper` 或本轮解锁 | 短答，不讲课 |
| 「再陪她说一句。」 | `ch3_player_protect` | 进入 3-5 或短 VO |

**冲突处理：**  
- Ai 要回去、玩家要备份 → 管理员：「我听**文件主人**的……也听**付钱的那位**的。你们先统一，或我按工单默认拷贝。」→ 再给一次二选一。  
- 双方都要倒回 → 走 Rollback（Bad）。  
- 双方都要备份 → 3-8。
