# 废萌事件三重回收表

规则：每一个日常事件必须同时满足三次阅读体验。

1. **第一次（Chapter 1）**：可爱 / 普通生活——禁止写成哲学台词  
2. **第二次（Chapter 2）**：心疼  
3. **第三次（Chapter 3 / Ending）**：世界观

第一章呈现方式：她只是很好相处、偶尔有点特别的人。  
自动门、夹娃娃、卖完的面包——玩家先笑，最后才懂。

## 使用规则（编剧自检）

写任何一个废萌段落前问：

1. 现在读，会不会觉得可爱？  
2. 知道真相后，会不会心疼？  
3. 它是否在解释「她」而不是炫耀设定？

三者缺一，重写或删除。
