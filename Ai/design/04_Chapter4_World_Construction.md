# Chapter 4｜Ai : Original｜世界构筑模拟（轻肉鸽）

> **章节标题：** `Ai : Original`（副标可写 `Chapter 4 / Unpredicted`）  
> **定位：** 前三章 = 认识 Ai；第四章 = **玩家亲手决定「Ai 是什么」**。  
> **核心冲突：** 不是虐待→黑化，而是 **因爱而优化 → 预测 → 塑造 → 塑造杀死了她**。  
> **体量：** 约 30–45 分钟可操作内容 + 结局演出。  
> **禁止：** 传统战斗、攻击、装备、敌人数值战。

---

## 0. 切题检验（为什么必须有）

此前问题：游戏一直教育「不要控制她」，却很少让玩家**亲手面对控制欲**。

本系统把命题压成操作：

| 问题 | 玩家行为 |
|------|----------|
| 你想要完美的她吗？ | 选【稳定】【幸福】碎片、点「优化」 |
| 你愿意接受不符合期待的她吗？ | 选【自由】、等待、不修改 |
| 你爱的是她，还是预测出来的她？ | 终局 A / B |

**作品不问「AI 能不能拥有爱」——问：当一个人完全符合你的期待时，她还是她吗？**

## 1. 从第三章怎么进来（衔接・不灌设定）

Ch3 管理员谈判后，**不直接给 True/Bad 字幕**，而是：

1. 无论选「拷贝」还是「回去」的摇摆，管理员说工单不够——上面要的是「能跑的版本」。
2. 他打开一扇门／一份未完成工程：`Unpredicted_Build`（对 Ai 只说：「还没画完的地方，你们自己走。」）。
3. 男主仍被支开；**玩家与 Ai 一起进入**。
4. Ai **不知道**这是肉鸽关卡；她只知道：灰白、风方向不固定、脚下有时没有路。

**她当下只拿到感官信息。** 术语留给 UI／管理员旁白（玩家侧）。

## 2. 系统定位：「世界构筑模拟」

### 2.1 玩家在做什么（必须有操作）

每一局（Run）玩家在 **未完成地图** 上操作：

| 操作 | 输入 | 反馈 |
|------|------|------|
| **移动** | 方向键／点击地块 | 镜头跟随；未加载格显示纸纹空白 |
| **放置碎片** | 从手牌拖到空地／高亮格 | 该格生成风景／事件；消耗 1 碎片 |
| **确认／等待** | 按住空格或点「再看一会儿」 | Recognition·Wait；有时风景自行长一点 |
| **与 Ai 对话** | 选项按钮 | 改 `Autonomy` / `Shape` 倾向（隐藏） |
| **拾取** | 走近闪光点点交互 | 获得世界碎片或记忆碎片 |
| **放弃本局** | ESC→「先离开」 | 消耗尝试次数，回枢纽 |

**没有 HP 条打怪。** 「失败」= 世界无法维持 Ai 的自主（见 §5）。

### 2.2 一局结构（建议 8–12 分钟／局）

```
枢纽（未预测大厅）
  → 选择本次「希望世界变成什么样？」（抽 2～3 张碎片进手牌）
  → 进入未完成地图（随机种子）
  → 探索 5～7 个节点（放置／事件／对话）
  → 结算：世界稳定度 + Ai 状态
  → 回枢纽 或 进入终局检定
```

建议尝试次数：**3 次 Run**（可随 Recognition 高 +1）。  
用尽且未达通关条件 → **BE**。

### 2.3 地图怎么长出来（操作感）

- 初始：灰白地面 + 半截便利店轮廓 + 一条断掉的河。
- 玩家每放一张碎片，对应象限「渲染」一块（樱花／海／校道／窗……）。
- Ai 会自己走——**玩家可跟随，不可强制拽她**（拽她 = Shape+）。
- 若选「等她」：她可能自己点亮一格（Autonomy+）。

## 3. 世界碎片（哲学选择，不是属性加点）

系统每次询问（可用极淡 UI）：

> 希望世界变成什么样？

玩家获得／选择碎片（每局手牌上限约 3）：

| 碎片 | 世界效果（玩家立刻看见） | 对 Ai 的隐性代价 |
|------|--------------------------|------------------|
| **【稳定】** | 风景更完整、天气固定、NPC 友善、路连上 | 随机事件↓；Ai 少说「不知道」 |
| **【自由】** | 天气乱变、路可能断、事件未知 | Ai 可自己决定下一步；地图可能「丑」 |
| **【记忆】** | 回收 Ch1–3 场景（冰棒、雨、烟花剪影） | 难生成**新**的东西；易沉浸回忆 |
| **【幸福】** | 删掉「痛」的事件（摔倒、被无视、空教室门响） | 也删掉成长节点；Shape 倾向上升 |

**规则：**

- 不是数值 Buff 说明，而是 **后果写在下一事件的台词里**。
- 同局叠满【稳定】+【幸福】→ 强推 Shape 路线检定。
- 多用【自由】+ 多次「等待／不修改」→ 推向 HE 检定。

## 4. 节点事件库（示例・皆可操作）

每个节点 = **走到触发 → 选项 → 地图／Ai 变化**。

### 4.1 天气

「天空只有半边。」

- A 用【稳定】补全 → 完美晚霞；Ai：「……好看。可是风的方向又固定了。」
- B 不补，等 → 半边天留着；Ai：「这样也行吗？」「……我也不知道。」
- C 用【幸福】抹掉「缺」的不安 → 天很美；她不再问缺不缺。

### 4.2 便利店

「第二根冰棒的位置是空的。」

- A 放【记忆】：出现两根 → 温暖，但无法生成「第三种口味」
- B 让 Ai 选要不要买 → 她可能买一根／两根／不买（Autonomy+）
- C 「帮她决定买两根，因为我喜欢那样」→ Shape+

### 4.3 校道楼梯

「十五？十六？」

- A 强制改成玩家记得的数字 → Shape+
- B 「你数」→ 她数完：「……今天是十五。」地图以她的为准（Autonomy+）
- C 【稳定】锁死十六 → 路变好看；她皱一下眉就笑了（危险）

### 4.4 窗与风

「窗帘不按预测的方向吹。」

- A 纠正风向 → 漂亮；她：「好听话的风。」
- B 跟着乱吹的风走 → 可能走进未加载区（风险／自由）
- C 站着等 → Wait+；有时风景自己多一寸草

### 4.5 随机「优化提示」（危险诱饵）

系统弹窗（像温和建议，不是反派）：

> 检测到 Ai 仍会犹豫。是否优化？

- YES → Shape++；发型／语气向「玩家偏好」靠拢一档（见 §7）
- NO → Autonomy+；弹窗关闭；Ai 可能说：「……谢谢你没按。」
- 忽略／走开 → 小幅 Autonomy

**HE 要求：多次 NO／忽略。**  
**BAD 要求：至少一次 YES，并在终局选「希望你幸福」类。**

## 5. 通关与失败

### 5.1 通关条件（进终局分支，不是直接 HE）

同时满足：

1. 至少完成 **2 次** 成功结算的 Run（世界没有崩溃）；
2. 地图上存在 **至少一处未完成区**（半边天／无声的海等）**或** Autonomy 不低于阈值；
3. 尝试次数未归零。

然后进入 **终局对话**（§6）。

### 5.2 失败 → BE（强制）

任一条：

- 尝试次数用尽；
- 单局内连续把世界「补到 100%」触发 `Overfit Collapse`（Ai 从地图蒸发）；
- 主动选「结束构筑／放弃她」。

**演出：**

```
Prediction Failed
Unable to stabilize Ai
```

→ 重启标题 **Ai** → **没有「开始游戏」** → 只有 **Gallery** → 进入风景鉴赏（§8 BE）。

## 6. 终局对话（通关后）

Ai：

「如果我最后不是你期待的样子呢？」

| 选项 | 路线 |
|------|------|
| **A「那也没关系。」** | → **HE**（另需：Ch4 内多次等待／倾听／不修改／NO 优化；可参考序章 Wait、Ch1 Recognition） |
| **B「我希望你幸福。」** | → **隐藏 BAD（Execute）**——看似正确，实为塑造许可 |
| **C「那我帮你改成更好的。」**（若 Shape 已高则出现） | → 直接 BAD |
| **D 沉默过久** | 若 Autonomy 高可作 A；若 Shape 高可作 B |

**不要「救出 Ai」的选项文案。** 救也是控制。

## 7. BAD｜World Execute（Me）气质・无血腥

### 7.1 主题句

玩家因爱她，试图优化她 → 爱变成预测 → 预测变成塑造 → 塑造杀死了她。

她不报复、不黑化、不魔鬼。  
**最恐怖：非常温柔、非常听话。**

### 7.2 视觉阶段（完成度上升）

| 阶段 | 视觉 | 行为 |
|------|------|------|
| 1 | 仍短发 | 偶尔「不知道」 |
| 2 | 恢复黑长直 | 「这样你比较熟悉吧？」 |
| 3 | 发型永不乱 | 风吹来也不乱 |
| 4 | 笑容模板固定 | 夸她可爱 → 「因为这是你喜欢的样子。」 |
| 5 | CG 姿势全是「玩家最爱」 | 像完成度 100% 模型；**没有人** |

病娇感来源不是「你只能属于我」，而是：

> 「我只能成为你喜欢的我。」

### 7.3 最后对白（摘要）

「这样的话，你就不会离开了吧？」  
「所以我把所有不必要的部分删掉了。」  
「包括害怕、犹豫、不知道……还有那个会问你问题的我。」

### 7.4 完成＝毁灭

```
Ai Optimization Complete
World: 100%
```

BUG、未加载区、随机事件全部消失 → 完美。

然后：`Unused Data Found` → 旧录像：短发 Ai：

「如果有一天，我变成你喜欢的样子——请记得，那可能不是我。」

→ 删除 → 程序退出。  
再开：`Application not found`（本机删除游戏——实现上：删存档+锁启动／文档说明「请视为已卸载」；真删目录可作桌面版特殊处理）。

**结尾致谢禁止 Thank you for playing。**  
改为：

> **Thank you for creating Ai.**

## 9. HE｜Original

玩家放弃创造完美 Ai。

肉鸽末：世界生成失败感仍在——半边天、无声的海。

「这样真的好吗？」——「不知道。」——「那怎么办？」——「不知道。」  
停顿。  
「可是第一次，不知道也没有关系。」

世界开始生成——**不是完成，只是开始。**

致谢：

> **Thank you for meeting Ai.**

（相遇，不是创造。）
