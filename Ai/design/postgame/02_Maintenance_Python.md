# 后日谈｜Maintenance（Python 真代码）

## 定位

全年龄向、有教学的 **真实 Python 修复**。  
不是伪代码小游戏：修完的脚本可复制，在游戏内 Shell（及可选本地）运行。

主题：理解规则与创造侧——玩家第一次不是改角色，而是碰构成世界的语言。

## 范围冻结（本期）

- **仅 Python**
- **题干固定**（关卡列表写死）
- **Bug 从固定变异池随机抽取**（每局不同坏法，仍可教）
- 通关奖励：跑出一个 **像素版「Ai 曾在的世界」**（校道／窗／便利店／云等）

## 玩家操作

1. 读错误表现（世界哪里坏了：云不渲染、楼梯数错……）
2. 打开故障脚本 + 提示
3. 改代码
4. 在游戏内 Shell 运行／跑断言
5. 成功 → 像素场景多一块／一句世界观真话（大白话，短）

## 关卡曲线（固定题干例）

| Lv | 概念 | 叙事挂钩（例） |
|----|------|----------------|
| 1 | 变量／字符串 | 世界名、地点名空了 |
| 2 | 条件 | NPC「哈？」模板乱触发 |
| 3 | 循环 | 鸟叫／脚步音频重复 |
| 4 | 函数 | 天空延迟加载（云晚半拍） |
| 5 | 列表／字典 | 楼梯级数 15／16 |
| 6 | 小模块组装 | 像素世界主循环能跑起来 |

每关：`broken_*.py` + `tests/test_*.py` + `hint.md`。  
随机 Bug：注释掉赋值、反转条件、off-by-one、错误默认值等——**不**随机到语法不可教。

## 运行要求

- 修复后脚本 **自包含**，不依赖游戏私有 API
- 游戏内：`python world_fix_0N.py` → 明确 stdout
- 可选：一键复制到剪贴板

## 像素世界奖励

全部（或核心）关卡通过后：

- 启动 `pixel_world` 沙盒：可走的像素校道／窗／便利店
- 云、风、第二根冰棒位等用代码关卡「点亮」
- 这是 **看见**，不是攻略结算

## 与祂的节奏（非强制恋爱）

- 初期：「这里。修。」
- 中期：问「为什么这个方案」
- 小时数／关卡阈值 → 可触发 Ai「有缘再见」（她去 Beyond 侧冒险）
- 之后更多与祂独处 → 才可能进隐藏助手线（见 03）

- 逻辑与 Ren'Py 分离；关卡数据化
