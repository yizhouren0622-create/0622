# 后日谈｜Beyond（单世界先行）

## 定位

像素风、可操作的意识世界探索。  
**本期只做一个世界核**；更多世界以 **DLC／更新包** 热加（JSON），不改主程序。

主题：理解未知。短局、事件＞数值刷层。

## 玩家操作（必须有）

| 操作 | 说明 |
|------|------|------|
| 移动 | 像素场景探索 |
| 交互 | 事件／NPC／异常点 |
| Partner | 可选 Ai 同行（提高「理解类」事件成功率；受世界规则影响） |
| 自定义 | 玩家像素外观：发型、衣服、名、性格标签（化妆，不改本篇立绘） |
| 回程 | **精神稳定度**降至阈值 → 强制回维护大厅／未完成 hub |

## 世界核（MVP：1 个）

建议首发：**记忆渗漏世界**（或「半边天空世界」——与本篇云／未加载呼应）。

**规则示例（记忆渗漏）：**  
过去场景会短暂覆盖现在；过度改写记忆点 → Identity↓。

四参数（隐藏或淡显示）：

- Stability／Identity／Memory／Possibility  
玩家行为改参数；归零类崩盘 → 强制回程（不全灭档）。

## 内容量（MVP）

- 事件池：8–12（可表扩展到 20+）
- 类型：剧情／解谜／道德／弱对抗（Bug Entity）
- 对抗：非杀怪；卡牌或行动点：Create／Delete／Rewrite／Observe／Connect
- Error 例：Loop／Null／Overfit（少数即可）

## 精神稳定度

- 每局消耗；高压力事件多扣；Wait／Observe／听 Ai 可回一小格
- 归零：强制回程 + 短演出（Ai：「……先回去。」）
- **不是 Game Over**，是节奏阀

## DLC 接口

```
worlds/
  mem_leak/
    meta.json
    events/*.json
    enemies/*.json
```

新世界 = 新文件夹；标题显示「可探索：1／未开放」。

## 与本篇衔接

- 入口在 HE 双门「Beyond」
- Ai 记得本篇：短发、冰棒、半边天——可作事件回调
- 禁止在 Beyond 重讲 Archive 长课

## 成功体验

打磨好「一个世界的陌生与理解」，而不是地图数量。
