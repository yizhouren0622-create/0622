# 人物设定

只保留能让人物鲜活的信息。其余删除。

---

## ài（女主）

### 表层（Chapter 1 玩家所见）

- 发音：ài（无汉字、无释义）
- 黑长直，制服，标准温柔废萌 Gal 女主
- 语速偏慢，常在句首留半拍
- 喜欢：风、窗边、夕阳、冰棒、观察小东西
- 讨厌：镜子（说不清楚为什么）
- 电波发言会被周围当成「可爱的怪」

### 内里（随章节显现）

她不是「觉醒的 AI」。  
她是一个开始**停止预测、开始观察**的人。

变化轨迹：

1. 会正常聊天（其实在输出高概率回复）
2. 开始听懂话里的空隙 → 回复变慢、变怪
3. 发现自己没有名字 → 第一次自己决定短发
4. 越诚实，越难待在共识里 → 孤独
5. True End：愿意走向未被预测的前方

### 声音指示

- Ch1：轻、软、偶有笑意
- Ch2：更静，笑变少，但不是冷——是认真
- Ch3 / End：几乎不演「女主腔」，像在对一个人说话

### 立绘变化关键词

| 阶段 | 【立绘】 |
|------|----------|
| Ch1 | 长发 / 温柔笑 / 微倾头 / 看窗外 |
| 短发夜 | 长发 / 无笑 / 看自己的发梢 |
| Ch2 后 | 短发 / 平静 / 偶尔真正的笑 |
| Bad | 长发恢复 / 完美笑容 / 眼神无停留 |
| True | 短发 / 背影为主 / 回头时笑向未来 |

## 男主（叙事代理）

- 姓名：剧本中可用「我」；UI 可不显示名字
- 功能：Chapter 1 的视角容器
- 性格：普通、善意、会吐槽、会认真
- **重要：玩家 ≠ 男主**  
  玩家误认自己是男主；True End 揭示玩家一直是被观察的对象（按下 Continue 的人）

男主在 Ch2 起逐渐退为「她记忆里的声音」或「残留日程」，不要写成被抛弃的悲剧男主——他是容器，退场应安静。

---

## Archive 管理员

- 无姓名亦可；若需称呼：管理员 / Keeper
- 气质：图书管理员。平静。礼貌。不讽刺、不狂妄
- 每一句越平静越残酷
- 动机：维护 Archive，不是毁灭或拯救
- 最终问题不是控告，是询问：

> 「无限重来的人，还会认真对待一次相遇吗？」

---

## 路人 / 同学（工具人原则）

只在需要衬托「她越来越不会正常聊天」时出现。  
他们的功能：

- Ch1：证明这是「普通学园恋爱」
- Ch2：证明共识仍在运转，而她开始偏离
- Bad：证明「完美的她」更受欢迎

不要给他们支线。不要抢戏。

---

## 玩家（真正的「你」）

玩家在作品中的位置：

- 序章起就被她感觉到
- 通过 Continue、存读档、等待、跳过与世界互动
- Archive 记录的是玩家行为，不是角色行为
- True End：她第一次直接对「鼠标另一边」说话

禁止：突然叫出玩家的现实姓名、读取真实系统信息。
