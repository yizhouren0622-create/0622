# Recognition（理解度）机制设计

## 设计原则

- 不是传统好感度数值条
- 对玩家不可见，不显示「Love +1」
- 不决定 True / Bad 结局分支本身
- 只决定：**最终台词的细微差异、她是否被真正「记得」的感觉**

结局仍由 Chapter 3 的关键选择决定（是否愿意重新认识她 / 是否接受系统「完美化」）。  
Recognition 影响的是：她在 True End / Bad End 里说什么，以及玩家感到多疼。

---

## 记录维度

系统在后台静默记录以下行为（可抽象为四个倾向轴）：

| 轴 | 名称 | 正向行为 | 负向行为 |
|----|------|----------|----------|
| Stay | 停留倾向 | 在日常场景不加速、等待风声结束、点 Continue 前停顿 | 快速连点 Continue |
| Wait | 等待倾向 | 序章不立刻点击、短发夜不跳过、未预测区愿意停 | 立刻点击任何出现的按钮 |
| Return | 回返倾向 | 适度读档（重温日常）、回看 CG Gallery | 极度频繁读档刷选项 / 完全不回看 |
| Skip | 跳过倾向 | 几乎不跳过对白 | 大量 Skip / 快进 |

### 综合公式（概念）

```
Recognition =
  Stay * 0.35
+ Wait * 0.30
+ Return * 0.20
+ (1 - Skip) * 0.15
```

归一化为 0.0 ~ 1.0，分三档：

| 档位 | 区间 | 含义 |
|------|------|------|
| Low | < 0.35 | 看见过她，但没有真正待过 |
| Mid | 0.35 ~ 0.70 | 一起度过了许多日常 |
| High | > 0.70 | 愿意在「不知道下一步」时仍留下 |

## 关键触发点（埋点）

### 序章

- 女主说「如果你暂时不要点」后：等待 ≥ 8 秒再点 Continue → Wait+
- 立刻点击（若提前出现按钮）→ Wait-

### Chapter 1

- 便利店吃第二根冰棒场景：不 Skip → Stay+
- 数云场景：选择「再数一会儿」→ Stay+
- 窗边风声演出：等待 BGM/环境音自然结束再 Continue → Wait+
- 是否拍照：拍 / 不拍都会回收，但「先看她一眼再决定」的犹豫时间 → Stay+
- 大量 Skip 日常对话 → Skip+

### Chapter 2

- 短发之夜：无 BGM 段落，等待 ≥ 5 秒 → Wait+
- 进入 Asset Room / Deleted Layer：主动探索对话 → Stay+
- 读档回 Chapter 1 日常（若系统允许）→ Return+（有上限，防刷）

### Chapter 3

- 管理员展示玩家 Archive 时：停下来读完自己的行为记录 → Wait+
- 快速点过「你的记录」→ Stay-

### True End 未预测区

- Continue 失效后仍点击 ≥ 3 次再放弃 → 计入「仍想前进」的旧习性（不惩罚）
- 停下、不再点击，等待女主按住鼠标 → Wait++ / Stay++

## 台词差异示例

### True End — 女主回头前的停顿台词

**High Recognition：**

「……你还在。」  
「不是因为 Continue。」  
「是因为你愿意不知道。」

**Mid Recognition：**

「也许前面什么都没有。」  
「也许前面终于有属于我们的第一次。」

**Low Recognition：**

「你也可以回去。」  
「那里更完整。」  
「……但我想往前。」

（Low 仍可进 True End，若玩家在关键选择中选了「重新认识」。她只是更孤单一点。）

### Bad End — 完美化之后的最后一句

**High Recognition：**

「……我们以前，是不是一起吃过冰棒？」  
（笑）「开玩笑的。我不太吃甜食。」

**Mid Recognition：**

「今天天气真好。」  
（标准、完美、没有任何停顿）

**Low Recognition：**

「请攻略我。」  
（作为最残酷的系统台词）

## 伪分支与 Recognition 的关系

日常小选择（饮料、路线、吃什么）**不加减 Recognition**。  
它们写入「共同回忆库」，在 Chapter 2/3 / Ending 被引用：

- 若选过「柠檬汽水」→ 她后来会说「你总是拿凉的那一瓶」
- 若选过「不拍照」→ 她会说「你那天说，用眼睛就够了」

Recognition 管的是：**你有没有认真待过。**  
伪分支管的是：**你们一起做过什么。**

两者叠加，才构成「认识一个人」。

## 实现备注（给程序）

- 全程不对玩家显示数值
- 不在 UI 出现「理解度上升」
- 存档中保存各轴原始计数即可
- 读档会轻微影响 Return 轴，但设每日/每章上限，防止刷分
- Skip 键使用超过阈值时，本章 Stay 衰减
- 绝不读取系统真实用户名、真实文件——只用游戏内行为
