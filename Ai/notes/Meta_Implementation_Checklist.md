# Meta 演出实现清单

原则：每个 Meta 必须推动情绪；删掉后人物关系变弱才保留。  
禁止：叫玩家真名、删存档、读系统隐私、惊吓、DDLC 式崩坏。

---

## 必须参与剧情的 UI

| UI | 参与方式 | 章节 |
|----|----------|------|
| Continue | 序章晚出现；短发夜晚出现；True End 失效 | Prologue / Ch2 / True |
| Touch（标题） | 点后不立刻开游戏；光标自检 | Prologue |
| 鼠标光标 | 标题自移动；True End 被她按住 | Prologue / True |
| ESC / 暂停 | 风声可漏入；她问「还在吗」 | Ch2 |
| 存档 | Ch1 夜「保存心情」；她 VO「多留一会儿」 | Ch1 |
| 读档 | Ch3 Archive 统计；管理员「书页变薄」 | Ch3 |
| 窗口大小 | 缩小时 VO「世界变窄了」 | Ch2 |
| Alt+Tab / 失焦 | 仅写入 Archive 统计，不弹窗惊吓 | Ch3 展示 |
| 截图 | 可选：截到她时，Gallery 多一张「未被安排的瞬间」 | Ch2 |
| CG Gallery | Deleted Asset（长发）；她 VO「还有人收藏着」 | Ch2 |
| 标题界面 | 通关后若久不点 Touch，回收序章台词 | Post-True |

---

## 禁止清单（验收用）

- [ ] 无 jumpscare
- [ ] 无突然全屏血字/崩坏脸
- [ ] 无删除用户存档文件
- [ ] 无读取真实用户名/路径/浏览器
- [ ] 无强迫关闭游戏
- [ ] Meta 台词均可翻译为「她的情绪」而非「作者在说话」

## 音响总则

| 段落 | BGM |
|------|-----|
| 序章 | 无；只有风 |
| Ch1 | 普通恋爱校园 |
| 短发夜 | **无 BGM** |
| Asset / Archive | 极简环境音 |
| Bad 完美日常 | 故意用回 Ch1 甜曲 |
| True 未预测区 | 无 BGM；风方向不固定 |

## 文本量参考

| 块 | 目标体验时长 |
|----|----------------|
| Prologue | 2~4 min |
| Chapter 1 | ~70 min |
| Chapter 2 | ~40~50 min |
| Chapter 3 | ~25~35 min |
| Endings | ~10~15 min |
| **合计** | **约 2.5~3 h** |

若实测不足：优先加长 Ch1 日常（同一废萌的「第二天变奏」），不要加设定讲解。
